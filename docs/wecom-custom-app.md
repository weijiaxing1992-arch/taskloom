# 企业微信自建应用通知投递

TaskLoom 可以把**新产生的站内通知**异步投递到企业微信自建应用。站内通知永远先写入本系统；企业微信不可用、配置变化或投递失败都不会阻塞业务操作，也不会删除站内通知。

默认处于 `mock`（模拟）模式：会记录安全的投递状态，但**绝不会向企业微信发起网络请求**。生产环境只有在所有条件满足后才会真实外发。

## 真实投递的全部前提

以下条件缺一不可：

1. 企业管理员在“企业管理 → 企业微信自建应用”保存有效的 CorpID、AgentId、应用 Secret、正式 HTTPS 域名和 `WW_verify_*.txt` 文件名，并打开“启用企业微信自建应用”。
2. 管理员显式打开“启用通知中心企业微信投递”。此开关只影响打开后新产生的通知，不补发历史通知。
3. 服务器环境变量为 `DEVFLOW_WECOM_MODE=live`。未设置时默认为 `mock`，开发与测试环境不会真实外发。
4. 成员在“个人设置 → 企业微信绑定”确认当前密码并完成企业微信官方网页授权。系统只接受接口返回的企业微信 UserId，绝不按姓名、邮箱、昵称或部门猜测对应关系。
5. 接收人仍处于启用状态、仍是当前企业成员，且对通知所属项目有访问权限。

任何一项在投递前发生变化，待投递任务会安全标记为“已跳过”而不会发送给错误的人员。

## 管理员准备清单

1. 在企业微信管理后台创建自建应用，设置应用名称、图标，以及需要接收通知的成员可见范围和消息发送权限。
2. 填写企业 ID（CorpID）、应用 AgentId、应用 Secret；Secret 仅加密保存，后续页面、审计和日志均不会回显。
3. 下载企业微信提供的 `WW_verify_*.txt`，由运维将原文件部署到正式域名根目录，例如 `https://taskloom.example.com/WW_verify_xxx.txt`。本系统只保存文件名，不保存或托管文件内容。
4. 在企业微信后台配置可信域名和授权回调域：`https://你的正式域名/api/auth/wecom/callback`；并将服务器真实公网出口 IP 加入企业可信 IP。不要填写浏览器 IP、内网地址或反向代理回环地址。
5. 在预生产先用一个非管理员测试账号完成绑定并触发一条测试通知，确认企业微信成员可见范围、跳转地址和消息内容正确后，再将 `DEVFLOW_WECOM_MODE` 设置为 `live`。

## 成员绑定与数据保护

成员绑定需要本地账号当前密码再次确认，并由一次性 `state`、同浏览器 HttpOnly Cookie、当前会话摘要、当前密码哈希摘要和配置版本共同保护。授权状态五分钟过期且只能消费一次；改密、登出、配置变化、账号停用或代访问都会使授权失效。

企业微信 UserId 使用独立 AES-GCM AAD 加密存储，且绑定到企业、TaskLoom 用户和 CorpID；数据库仅额外保存不可逆摘要来保证同一企业微信身份不会绑定到多个账号。读取接口、通知页面、审计记录和服务日志均不返回 UserId、Secret 或 access_token。成员被移除、删除或主动解绑时，绑定及待发送任务会被清理或跳过。

## 投递行为与失败处理

- 通过 `user_notifications` 的数据库触发器入队，覆盖通知中心的全部类别（提及与回复、分配与交接、需求与状态变更、其他动态，以及自动化规则产生的通知）。
- 消息包含中文通知分类、标题、摘要、项目、操作人、关联对象摘要和受控的站内详情跳转链接；长消息按现有安全长度规则分段投递。
- 网络请求只使用固定的企业微信官方 API 域名、可信 HTTP 客户端、无代理、无重定向和公网地址校验。access_token 仅在进程内短时缓存，不落库、不写日志。
- 企业微信返回暂时性错误时最多尝试 6 次，采用指数退避；非临时错误、解绑、权限变化或配置变化会记录中文可诊断状态而停止重试。企业微信侧也开启重复消息抑制。
- 管理员配置页仅展示投递状态、计数、类别和标题；不会展示通知正文、用户标识或凭据。

## 内部接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/organization/wecom-app` | 企业管理员，禁止代访问 | 掩码配置、投递开关、统计和最近安全状态。 |
| PATCH | `/api/organization/wecom-app` | 企业管理员，禁止代访问 | 同源 JSON：`corpId, agentId, origin, verifyFilename, secret?, clearSecret?, enabled, notificationDeliveryEnabled, version`。 |
| GET | `/api/profile/wecom-app` | 当前成员，禁止代访问 | 本人绑定状态；不返回企业微信 UserId 或令牌。 |
| POST | `/api/profile/wecom-app/bind` | 当前成员 | 同源 JSON，需 `password`；只在 `live` 模式和有效配置下创建官方授权地址。 |
| POST | `/api/profile/wecom-app/unbind` | 当前成员 | 同源 JSON，需 `password`；删除本人绑定并停止待投递任务。 |
| GET | `/api/auth/wecom/callback` | 一次性授权 state | 换取企业微信官方 UserId 后绑定当前账号，完成后固定跳回个人设置。 |

这些是内部 Cookie 会话接口，不是开放 REST/MCP Token 接口。不得将管理员 Cookie、应用 Secret、access_token 或 `WW_verify` 文件内容交给第三方。
