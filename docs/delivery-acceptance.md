# TaskLoom 社区候选版验收说明

## 本次范围

本说明对应 TaskLoom 0.2.0-rc1 预发布版。交付范围为公开源码、Vue 桌面应用、React 手机工作台、Go API、SQLite 和配套文档；不沿用历史商业部署或原生客户端的验收结论。手机工作台包括我的工作、需求、迭代、通知四个入口，复杂编辑仍可使用桌面版。

本文件说明需要核对的范围，不是无保留的生产验收证书。真实执行结果以对应提交的持续集成记录及发布验证记录为准，不从旧版本测试成绩推断当前提交已经通过。

## 自动化检查

从锁定依赖构建，依次运行 go test ./...、pnpm typecheck、pnpm build 和 pnpm test。前端运行器自动发现 scripts/ 中的 test-*.mjs 与 *.test.mjs，不排除产品功能套件。检查包含账号与首登改密、权限和身份隔离、需求及测试协作、移动阅读、通知、AI 模拟、文档渲染及社区构建边界。

纯商业 Flutter/macOS 开发包测试已移除，因为社区版没有该打包目标。原有产品行为断言继续保留，门户地址、私有本机启动器和原生桥接源码依赖改为当前社区入口验证。编译或交叉编译成功不能代表某平台已完成真实部署。

## 业务与权限验收

在独立数据库完成 Admin / 123456 首次改密，验证未改密业务受限、重新登录以及进程重启后账号仍可用。用产品、研发、测试和只读账号分别核对需求、迭代、测试执行、缺陷、通知和授权下载。账号停用、项目撤权、账号切换和并发修改需要验证旧请求不会泄露或覆盖其他身份的数据。

检查手机四个入口、长正文、代码、附件、通知过滤、未读状态和深链接。公开分享只包含经确认的标题、描述和验收快照，需验证七天到期、撤销和生成者失权后的失效行为。工作量趋势不得解释为个人绩效结论。

## 外部服务与上线保留项

AI 测试使用模拟响应时，只能说明交互和协议边界；真实服务配置、质量、延迟和费用需另行评估。微信及企业微信自建应用需要有效凭据、成员绑定、正式域名和独立联调；演示启动器的 mock 模式不能作为真实投递成功证据。

目标服务器安装、TLS、依赖漏洞审计、压力测试、手机浏览器人工验收、异地备份恢复和业务验收仍由部署方执行。记录日期、版本、环境、结果、问题与负责人，完成这些工作后再决定是否正式开放。
