# 功能清单与验收范围

## 业务模块

| 模块 | 当前交付能力 | 重点验收 / 边界 |
| --- | --- | --- |
| 账号与身份 | 登录、退出、首次改密、会话、代访问、停用保护 | 企业权限与项目权限分离；不提供公开默认生产密码 |
| 项目空间 | 创建、检索、收藏、成员差异配置、归档、恢复、删除 | 删除受权限、项目状态及代号确认约束 |
| 需求 | 创建、富文本、双击正文编辑、草稿、分类、标签、自定义字段、人员职能与权重 | 乐观并发冲突不静默覆盖；子项按本页父子关系展示 |
| 需求关系 | 子需求、关联、跨项目依赖、阻塞影响 | 仅有权对象可见；父项被筛掉时子项仍保留 |
| 导出 | PDF、完整 JSON / Markdown、列表导出 | 完整导出含子需求、测试资料、评论；附件为元数据与授权链接 |
| 迭代 | 创建、排期、工作项、开始 / 完成、状态、概览、看板、团队 / 进度 / 权重 | 迭代负责人字段已移除；不会用人员字段代替工作量 |
| 缺陷 | 创建、描述、草稿、指派、验证、状态流转、关联需求与测试、评论 | 无权写入及非法状态转移拒绝 |
| 测试协作 | 测试设计、目录 / 用例库、步骤、评审、计划、执行、结果、质量报告 | 需求内创建 / 编辑 / 关联已有用例；不覆盖其他需求的关联 |
| 我的工作 | 待办聚合、筛选、收藏、跨项目跳转 | 项目切换后重新授权 |
| 搜索 | 全局 / 项目检索、分页、类别筛选 | 无权限内容不可通过搜索泄露 |
| 通知 | 分配、状态变化、提及、未读、读状态、通知跳转 | 账号隔离；外部通道需真实凭据与投递联调 |
| 自动化 | 需求状态触发、绑定职能收件人、试运行、启停、执行记录 | 默认关闭；试运行不发送；只取有效绑定成员 |
| 组织管理 | 部门树、成员导入导出、逐个 / 批量启停、机器人配置、项目角色、邀请审批 | 高权限成员保护；批量动作受权限及范围限制 |
| 仪表盘与报表 | 项目概览、工作量、路线图 / 依赖、风险摘要 | 指标受数据完整性影响，不直接等同绩效 |
| 审计 | 项目变更历史、筛选、分页、深链接 | 审计敏感字段脱敏 |
| AI 集成 | AI 服务配置、辅助标题 / 测试、开放 REST API / MCP、上下文读写 | Token scope、期限、项目绑定、If-Match 与幂等键 |
| 个性化 | 语言、主题、扁平组件、可收起侧栏、导航排序、本机布局记忆 | 浏览器布局按身份隔离，不写为团队配置 |
| 水印 | 账号、时间、IP 展示 | 是可见提醒而不是不可篡改的泄密追踪机制 |
| 服务器监控 | OS / CPU / 内存 / 磁盘 / Go 进程 / SQLite 状态和风险 | 仅企业管理员；站外告警需 CloudMonitor |
| 帮助与交付 | 使用手册、开放 / 内部 API、部署与验收资料 | 文档与源码包同源；中文文档不会随切换语言自动翻译 |
| 官方门户 | 产品介绍、工作台入口、macOS 测试包下载 | 公网域名和后台地址须部署时配置 |
| macOS 原生 | Flutter 独立客户端源码与既有 arm64 测试 DMG | 未公证、非完整产品；不宣称 Web 功能全部原生验收完成 |

## 版本范围与职责

Web + Go 服务端是本轮主要验收对象。编译产物提供 Linux amd64 和 macOS arm64 服务端（后者用于本机调试），不是两套不同数据库。原生 DMG 元数据 completeProduct=false / notarized=false，保留其测试标识。

本轮自动化覆盖的是仓库现有回归契约与新增缺陷测试；浏览器扫描验证真实页面加载，不等于每个权限组合、所有用户业务数据、第三方系统都已人工验收。

生产上线前业务负责人应完成典型项目 UAT：需求 → 子需求 → 迭代 → 用例 → 执行失败 → 缺陷 → 修复验证 → 通知与导出，分别使用产品、研发、测试和只读账号；留下签字 / 日期 / 问题单。不要在真实生产业务上运行破坏性测试。
