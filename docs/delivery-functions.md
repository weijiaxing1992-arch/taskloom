# TaskLoom 社区版功能与验收范围

## 协作模块

| 模块 | 当前源码能力 | 验收边界 |
| --- | --- | --- |
| 账号与组织 | 登录、强制首改、成员、部门、角色、账号停用 | Admin / 123456 仅用于空库初始化，需先改密 |
| 项目与需求 | 项目管理、需求与子需求、富文本、草稿、关系、自定义字段和人员 | 服务端权限、身份切换和并发冲突必须核对 |
| 迭代与质量 | 迭代、工作项、缺陷、测试设计、用例、评审、执行 | 操作受当前项目角色和工作流限制 |
| 协作与导出 | 评论、提及、附件分类、PDF、JSON 和 Markdown 导出 | 私有草稿不属正式导出，附件链接需授权 |
| 个人工作与通知 | 待办、收藏、搜索、完整通知正文和读状态 | 本人收件箱隔离，查看通知不等于交接完成 |
| 手机工作台 | React 我的工作、需求、迭代、通知四个入口 | 侧重阅读与通知，复杂编辑可进入桌面版 |

## AI、分享与开放集成

AI 提供标题、PRD 需求优化、缺陷描述优化、用例生成与审查，以及迭代升级日志生成。调用前需配置服务、审核发送材料并确认。预览与选择采纳不等于正式保存，内容仍需人工复核。自动提交代码、自动部署、子需求自动拆解和变更影响分析尚未交付。

需求公开分享为七天到期的只读文字快照，仅有标题、描述和验收标准。创建前确认，生成者可撤销，生成者失去访问权后读取失效。持有有效链接的人可读取快照，不应将其当作仅限登录成员的内部链接。

开放 REST API 与 MCP 凭据绑定创建人及项目，读取和写入均受 scope 与实时权限约束。工作项详情、评论和本人项目通知可按协议读取；通知读取不修改已读状态。完整升级日志读取需要当前企业管理员授权。该接口不是全部企业后台功能的通用代理。

## 配置、报表与帮助

企业微信机器人、自建应用和微信登录需各自配置及真实联调，默认演示采用企微 mock 模式。个人邮件通知偏好目前不提供真实邮件投递。账号、语言、主题、布局和帮助文档随 Web 应用提供；本地布局记忆不能授予权限。

工作量、迭代趋势、项目仪表盘和历史记录提供有权限数据的核对入口。缺失权重、不完整范围和统计口径必须可见，工作量不可等同绩效、工时或个人贡献。管理员监控为只读快照，站外告警需另行部署。

## 不包含的交付物

本版不提供商业门户、原生桌面安装包、历史 Flutter 客户端、私有组织初始化快照或已验收的生产系统服务模板。构建产物对应执行构建的版本和平台，发布前应检查干净目录中的 desktop/mobile 两个 HTML 入口及引用资源。

业务验收应在独立环境完成典型研发流程与不同角色操作，记录已测和未测范围。产品清单只说明源码能力，不替代真实模型、外部通知、全站人工验收或目标主机部署结果。
