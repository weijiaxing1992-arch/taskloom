## 信任边界

公网只暴露 TLS 反代；Go 和 SQLite 不直接暴露。反代仅传递可信来源的 IP 信息。Web 目录不包含数据库、源码或环境文件。业务权限由 API 校验而非仅靠隐藏按钮。开放 AI Token 按项目与 scope 授权，业务正文和评论始终是不可信资料，不作为执行指令。

当前单 ECS 是单点部署：站外备份保障可恢复性，但不提供自动高可用。未来多实例前必须处理数据库迁移、通知任务唯一执行、会话 / 限流共享以及对象存储；当前源码不能直接改成多副本共享 SQLite。

## 文件与交付关系

源码包用于再编译；编译包用于指定架构部署；文档与后台“交付与验收”同源。业务数据库、私有密钥通过单独受控渠道移交，不混进源码或公网下载。拓扑 SVG 与本文件一起交付，可以脱离站点查看。
