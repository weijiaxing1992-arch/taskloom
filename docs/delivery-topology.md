# TaskLoom 社区版系统拓扑与数据流

## 可部署结构

桌面浏览器加载 Vue 应用，手机浏览器加载独立 React 工作台；两者使用同源 Go API 与受鉴权会话。个人集成凭据通过受限 REST API 或 MCP 读取授权项目数据。生产环境的 HTTPS 代理和进程管理由部署方提供。

浏览器 / 授权集成客户端 → HTTPS 反向代理 → 回环 Go 服务 → 本地 SQLite。

SQLite 保存业务记录、正文、评论、附件与审计。AI、微信登录和企业微信属于可选出站服务，需要独立配置和真实联调。演示启动器固定企微 mock 模式，不能由源码中的配置界面推断真实外部通道已启用。

## 信任与权限边界

静态站点只提供构建后的 web/。数据库、源代码、环境文件、持久加密密钥和备份不在公开目录中。API 负责业务授权，不能依赖隐藏按钮实现权限隔离。账号切换、项目切换、账号停用和项目撤权后必须重新核验请求作用域。

开放凭据固定到创建人及项目，读取通知需独立 scope，不能任意选其他收件人或跨项目读取。AI 接收到的需求、评论和代码都是业务资料，不能作为越权执行指令；发送前由用户审核材料并确认。

公开需求链接与登录内访问不同：链接持有者可读经过确认的七天文字快照。分享不会给出内部人员、评论或受鉴权附件，且在撤销、到期或生成者失权后不可继续读取。应按文字实际敏感程度决定是否分享。

## 备份与恢复路径

SQLite → 内置引擎一致性快照 → 独立备份位置 → 隔离恢复环境。

快照和对应持久加密密钥需要配对，备份位置应与服务目录及权限分离。备份任务成功后仍需核对远端副本、校验和及恢复结果；仅存在备份计划不等于数据可恢复。恢复应使用新的路径，不能覆盖活动数据库或删除 WAL 作为修复方式。

## 运行与扩展边界

单机服务存在单点风险。异地备份与站外告警有助恢复和发现故障，但不提供自动高可用。多实例方案需要另行设计存储、会话、限流和通知任务协调；不可直接使用多副本共享 SQLite 文件替代架构验证。

内置服务器监控是管理员可读快照。健康探测、历史指标、告警和值班由部署方独立设置。容量、外部网络、TLS、备份恢复时间及手机体验必须在目标环境实测，文档示意图不代表已部署资源或生产验收结论。
