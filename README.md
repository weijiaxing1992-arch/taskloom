# TaskLoom · 研织

**开源、可自部署的 AI 研发协作与项目管理工具，面向寻找 TAPD / Teambition 替代方案的团队。**

[English](README.en.md) · [使用手册](docs/product-handbook.md) · [API 文档](docs/internal-api-reference.md) · [路线图](docs/OPEN_SOURCE_PLAN.md) · [安全说明](SECURITY.md)

让需求可理解、协作可追溯、AI 可参与。用一个工作空间连接需求管理、敏捷迭代、缺陷跟踪、测试用例、讨论和交付。

> 当前为 **0.2.0-rc1 预发布版**，适合评估与反馈；不承诺与 TAPD / Teambition 功能完全对等，也不关联或获得它们的官方认可。生产使用前请验证备份、权限、通知与部署环境。

## 为什么使用 TaskLoom？

- **研发协作闭环**：项目空间、需求与子需求、迭代、缺陷、测试用例与执行记录。
- **AI 辅助需求与质量管理**：以 PRD 视角优化需求，按复现步骤、实际结果和预期结果优化缺陷；可检查发送材料、预览新增段落并逐项采纳，之后仍需人工保存。也支持标题、用例生成和用例审查。
- **面向 AI 编程协作**：导出需求 JSON / Markdown，整合关联信息供模型理解；提供 API 读写集成能力。导出范围以使用手册为准。
- **研发资料集中管理**：Markdown、代码片段、评论、附件分类和关联内容，减少在多个工具间搬运资料。
- **个人工作与通知**：查看与自己相关的工作、收藏及通知完整正文，按项目、人员或部门搜索；搜索命中文字黄色高亮。个人集成凭据可分页读取有权工作项、详情、评论及本人当前项目通知，受实时权限和 scope 限制；读取通知不会自动标为已读。
- **桌面与手机**：Vue 3 桌面业务应用，React 手机工作台提供“我的工作、需求、迭代、通知”四个入口，共用会话和受鉴权 API。手机端侧重阅读、筛选与通知处理，复杂编辑可进入桌面版。
- **自部署与可控数据**：TypeScript 前端、Go API、SQLite。AI、微信登录、企业微信机器人及自建应用需部署方单独配置。演示启动器强制企微模拟模式，不代表真实通道已接通。
- **分享、升级日志与趋势**：需求可生成七天到期、可撤销的只读正文快照链接；生成者失去访问权后链接失效。升级日志可预览和导出，AI 生成需配置与人工复核。工作量趋势用于规划与数据核对，不能等同个人绩效。
- **迁移起点**：支持 TAPD PDF 需求导入流程。导入前核对字段与人员匹配，不保证所有导出模板无损兼容。

## TAPD / Teambition 开源替代场景

如果你在寻找 TAPD 平替、Teambition 平替、开源需求管理系统、敏捷项目管理工具或可私有化部署的研发协同平台，可以从以下流程试用：

| 需求场景 | TaskLoom 对应能力 |
| --- | --- |
| 管理需求池、拆分工作 | 需求、子需求、个人模板、工程师字段 |
| 管理研发计划与缺陷 | 迭代、工作项、缺陷跟踪 |
| 关联需求与测试 | 测试用例、执行、AI 生成与审查 |
| 与 AI 编程助手协作 | JSON/Markdown 导出、API 集成 |
| 从既有工具迁移 | TAPD PDF 导入与字段核对 |

这是使用场景说明，不是竞品功能或价格比较。自动子需求拆解、自动代码提交和变更影响分析尚未实现。

## 快速启动（源码）

需要 Node.js >=22.12、pnpm 11.19.0，以及 go.mod 指定的 Go 1.27.1。只支持你有权限管理的独立数据库。

```sh
git clone https://github.com/weijiaxing1992-arch/taskloom.git
cd taskloom
pnpm install --frozen-lockfile
pnpm build
go build -o server ./cmd/server
cp -R dist web
node start.mjs
```

访问 http://127.0.0.1:8080。启动器生成本机随机会话密钥，将数据写入当前目录 data/，默认只监听回环地址。再次构建时应使用新的发布目录，不混入历史网页资源。

**首次账号：Admin；首次密码：123456。登录后必须修改密码。** 未改密时业务接口受限，服务端拒绝非回环监听。初始化期间也不要配置公网反向代理；远程主机请通过 SSH 隧道完成首次改密。其他示例成员的密码随机生成且不公开，由管理员重设。

预置的是星河示例企业、8 个部门和 11 位虚构成员，不包含原企业用户或数据库。不要将历史商业版本数据库直接导入社区版。

## 架构与目录

```text
桌面 Vue / 手机 React → Go HTTP API → SQLite
                    └→ 可选 AI / 微信 / 机器人服务
src/       Vue 页面与组件、mobile-react 手机工作台
cmd/       Go 服务端和管理工具
docs/      使用、API 与运维文档
scripts/   构建及测试工具
```

本版发行 Web + Go，暂不提供社区 DMG 或历史 Flutter 客户端。环境变量、部分存储键与 MCP 工具名保留 DEVFLOW/devflow 兼容前缀；当前 Web 请求头使用 X-TaskLoom-*。

## 测试与已知限制

```sh
go test ./...
pnpm typecheck
pnpm test
```

测试脚本自动发现 scripts/ 下所有 test-*.mjs 与 *.test.mjs 套件，覆盖产品行为、权限隔离、初始化及社区构建边界。自动化通过或 Linux 交叉编译均不代表完成目标服务器生产验收；AI 和外部通道的模拟测试不代表真实服务质量评测。发布前仍需在独立环境验证全站操作、依赖漏洞、性能基线与异地备份恢复。请参考 [社区验收说明](docs/delivery-acceptance.md)。
